**Что получилось:**

- Нейросеть ответила, что в этом чате у неё нет доступа к VS Code и GitHub, и собрала репозиторий в своей среде с git-историей, отдав его архивом.

- Изображения, видео проекта, PDF-программа, QR-код и афиша сгенерированы скриптами на Python.
- Первый коммит — исходный результат без правок.

**Что пришлось исправить (найдено автоматической проверкой в браузере на 375/768/1280 px):**

3. Убрана ссылка на `apple-touch-icon.png` — по ТЗ изображения только WebP/JPEG.
4. В скриншоте проекта «Кот и лазер» не отображался эмодзи и луна перекрывала счёт — заменено на текст «ОЧКИ 12».
