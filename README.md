## Структура

- 8 страниц и `404.html` — статический HTML, CSS и JavaScript без сборки.
- `js/analytics.js` — все события GA4 (таблица — `docs/events.md`).
- `js/form.js` — форма заявки, UTM-метки, отправка в Apps Script.
- `apps-script/Code.gs` — приёмник заявок.
- `docs/` — журнал запросов к нейросети, таблица событий, реестр UTM, источники изображений, аналитическая записка, афиша и QR.
- `docs/setup.md` — что настраивается вручную в Google, Instagram, ManyChat и DataLens.
- `screens/` — снимки проверок.

## Как запустить локально

Открыть папку в VS Code и запустить расширение Live Server, или в терминале: `python -m http.server 8000` и открыть http://localhost:8000.
